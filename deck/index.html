02 · Why it is still unsolved

Fit tech promised 30–40%. It delivered 2–8%.

Promised

30–40%

Delivered

2–8%

Return‑rate reduction claimed by virtual‑fit and size‑recommendation vendors vs. reduction retailers measured post‑deployment.

True Fit · 3DLOOK

Predicts size before the sale. Learns from clicks.

Narvar · Loop

Moves the box after the sale. Never asks why.

Returnalyze

Reports the rate. Stops before the cause.

All three learn from engagement data captured before the sale. The signal that explains a return only exists after it.

Pre‑purchase behavior predicts intent. Only outcome data explains returns.
